# ARM64 PC-relative迁移

固定原V3的ZNV3Relocate/EncodeB为算法基线，仍使用同一branch/literal/ADR字段和terminal规则。新C模块对符号扩展、目标加减、PC差和范围全部使用有界无符号运算；禁止将负数左移或任意uint64转换为int64后相减。BC.cond不能在未知语义下原样复制，明确Unsupported。失败不修改输出。

接口采用preferred VA：ADRP页边界必须是实际VA页，不能假设所有镜像基址永远页对齐后把RVA视作VA。源指令必须在给定半开窗口内；目标位于窗口内拒绝，超出imm26/19/14/21范围拒绝。仍不宣称支持任意未来ISA/间接控制流证明或整个emit。

原直接branch解码从StaticPlan删除，统一进入NMARM64Relocation.c，避免再生成一份符号扩展实现。代码只生成指令值，不读取或修改执行内存。

测试：新算法以独立解码验证23997个目标保真用例及边界；原函数hash提取用于24000组定义良好输入结果对照。负立即数触发旧代码负数左移UB，通过独立子进程UBSan明确复现，预期失败证据不会当原函数通过；新算法负偏移由ASan/UBSan检查。实际结果以CI日志为准。
